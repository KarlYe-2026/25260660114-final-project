# 每日 QQQ "趋势+估值"复合观察 — 任务说明

> 长程工作流（long-running workflow）任务定义。实现与验收均以本文件为准。
> 本版取代旧方案（NAV 折溢价参考价），改为"趋势 + 估值"三信号复合判断。

## 1. 任务概述

每个美股交易日收盘后，对纳斯达克100ETF（QQQ）进行"趋势+估值"复合判断，计算三个低估信号：

| 信号 | 定义 | 类型 |
|------|------|------|
| S1 | 收盘价 < 200 日均线（MA200） | 趋势 |
| S2 | 收盘价 < 50 日均线（MA50） | 趋势 |
| S3 | 当前 PE(TTM) < 历史 PE 中位数 | 估值 |

**判定规则（唯一）：**

```
n_signals = S1 + S2 + S3          （每个信号取 0/1，满足为 1）
n_signals ≥ min_signals_required  → 信号 = "建议关注"
否则                              → 信号 = "观望"
```

- `min_signals_required` 默认 2，为可配置参数（见第 9 节参数版本演进）。
- 比较一律为**严格小于**：`close == MA` 或 `close == PE 中位数` 时该信号计 0。
- **降级规则：** 若 PE 数据为 n/a（见第 5、6 节），规则降级为"**S1 与 S2 同时满足才输出建议关注**"（即 S1 AND S2 → 建议关注，否则观望），且必须在估值 CSV、信号文件、状态文件三处明确标注 `rule=degraded_ma_only` 及降级原因，严禁静默降级。

## 2. 目标用户

个人研究者。目前手动查看行情并手工计算均线与估值对比，本工作流将这一日常动作自动化、留痕化。输出仅供本人研究观察（免责声明见第 10 节）。

## 3. 阶段与依赖

工作流固定为四个阶段，每步的输入来自上一步的输出，不得跳步：

```
① 取数 ──→ ② 计算 ──→ ③ 检查 ──→ ④ 信号
```

| 阶段 | 输入（来自哪一步的输出） | 输出 |
|------|--------------------------|------|
| ① 取数 | `asof` 日期（定时任务给定或 `--asof` 手动指定） | 原始数据快照：价格序列 + PE 快照（第 7 节），落盘 `data/raw/` |
| ② 计算 | ① 的原始快照文件 | 估值 CSV 行：close、MA50、MA200、PE(TTM)、历史 PE 中位数、S1/S2/S3、n_signals、rule、signal，追加至 `data/processed/qqq_valuation.csv` |
| ③ 检查 | ① 的快照 + ② 的估值行 | 校验结论（断言清单见第 8 节）写入审计日志；任一断言失败 → 当日运行记 `validation_failed`，信号作废，不进入 ④ |
| ④ 信号 | ③ 检查通过的估值行 | 信号文件（人读报告）+ 状态文件更新 |

## 4. 重复触发条件

- **生产触发：** 每个美股交易日收盘后运行一次，由系统定时任务触发（配置与安装方式见 `docs/notes/scheduling.md`）。
- **手动回跑：** 支持 `--asof YYYY-MM-DD` 参数回跑任意历史交易日，用于调试、验收与补数。回跑同样受第 6 节信息截止约束。
- 非交易日（休市）不产出新信号；运行检测到 asof 非交易日时记 `not_a_trading_day` 正常退出。

## 5. 允许的输入与数据来源

- **价格：kimi-datasource 插件 `stock_finance_data`**（`stock_finance_data_get_price`，ticker `QQQ.O`，显式 `adjust=none` 锁定**未复权**口径，日线，单次最长 3 年窗口，覆盖 ≥ 250 个交易日，满足 MA200 窗口）。原始响应由 MCP 调用落盘 `data/raw/asof-*/`，并附 `_fetch_request.json` 留档真实请求参数与时间；独立脚本（`src/fetch_data.py`）只读取校验该原始文件，缺失即报错。
- **PE(TTM)：蛋卷基金公开接口**（danjuanfunds.com — /djapi/index_eva/pe_history/NDX?day=all，周度序列）。插件全部数据源均无 PE 历史序列（`sp_data` 不覆盖 ETF、`stock_finance_data` 无估值接口、插件无指数估值源，探测记录见 `docs/notes/data-availability.md`）。**PE 采用 NDX 指数口径，作为 QQQ 的代理**；蛋卷口径与第三方（如 multpl）存在差异。
- 曾评估的候选源：Yahoo Chart API（query1/query2）2026-11-10 在本机网络全部被 403 封禁（含 cookie+crumb 流程，属边缘节点 IP 级封锁），弃用；插件 `yahoo_finance` 日线为后复权口径，不与未复权价格混算，仅可作交叉验证。
- 严禁用随机数、均值填充、前向填充等方式伪造或冒充数据。
- **历史 PE 序列：** 蛋卷周度序列取每月最后一个 ≤ asof 的观测聚合为月度值（口径见 `data/raw/asof-*/_meta.json`），历史 PE 中位数只取 `date ≤ asof` 的月度样本计算；评估月无观测时 PE 记 n/a 并触发第 1 节降级规则。
- **取不到数据时：** 必须报错停止（状态 `error`）或将对应字段显式标 `n/a` 并按降级/缺失规则处理，绝不允许留空、填 0 或沿用旧值冒充当日值。

## 6. 信息截止时点

- 只允许使用**不晚于 asof 日期可得**的数据：`max(date) ≤ asof`，T 日自身收盘数据可用（信号在收盘后生成），T 之后的数据严禁出现。
- 历史回放（`--asof`）必须先把数据截断到 asof 再计算，rolling 窗口（MA50/MA200/PE 中位数）只含 `date ≤ asof` 的样本。
- 严禁未来函数（如 `.shift(-1)`）；审计日志记录每次运行的数据截止日 `data_asof` 供复核。

## 7. 产出物清单

| 产出物 | 路径 | 说明 |
|--------|------|------|
| 原始数据快照 | `data/raw/YYYY-MM-DD.csv` | 当日价格序列 + PE 快照，附数据源、接口名、抓取时间戳；只追加，永不修改 |
| 估值 CSV | `data/processed/qqq_valuation.csv` | 逐日追加：`asof, close, ma50, ma200, pe_ttm, pe_hist_median, s1, s2, s3, n_signals, min_signals_required, rule, signal`；缺失字段填 `n/a` |
| 信号文件 | `report/YYYY-MM-DD.md` | 当日人读信号报告：三个信号逐项数值与来源、是否降级及原因、最终信号、免责声明 |
| 状态文件 | `.state/state.json` | 最近一次运行状态（覆写）：run_id、data_asof、status、rule、signal、各产物路径 |
| 审计日志 | `.logs/YYYY-MM-DD.log` | 每次运行的完整终端输出留痕：取数调用、断言结果、退出码；验收证据从中摘录（第 8 节） |

## 8. 验收标准

1. **来源可溯：** 估值 CSV 与信号文件中每个数值必须附来源（数据源、接口、抓取时间）；审计日志记录每次插件调用的原始返回。
2. **缺失纪律：** 缺失值一律标 `n/a`，不得填 0、不得静默跳过；PE 缺失时降级标注三处齐全（估值 CSV、信号文件、状态文件）。
3. **真实证据：** 所有核验证据必须粘贴**真实终端日志**（从 `.logs/` 摘录），严禁编造或手填"预期输出"。
4. **断言清单（检查阶段逐条执行）：**
   - 快照 `max(date) ≤ asof`，日期无重复、严格递增；
   - 价格行数 ≥ 220（MA200 窗口 + 余量），MA50/MA200 重算值与估值 CSV 之差 < 1e-6 × 价格；
   - PE 中位数样本全部满足 `date ≤ asof`，样本数 ≥ `min_pe_history` 才允许 S3 非 n/a；
   - 按规则复算信号与估值 CSV 一致；`close == MA` 或 `close == 中位数` 时对应信号必须为 0；
   - 降级日 `rule=degraded_ma_only` 且信号与"S1 AND S2"复算结果一致。
5. **场景测试：** 手算核对（任一日人工复算 MA 与中位数）、历史回放（`--asof` 重跑已知行情日，方向与市况常识一致）、缺失注入（删 PE → 必须降级标注）、前视注入（把快照某日期改到 asof 之后 → 断言必须 FAIL）、端到端（定时任务手动触发一次，五类产物齐备、state.json 正常）。

## 9. 为什么需要持久化工作流而不是一次性脚本

1. **跨日状态延续：** 历史 PE 中位数没有现成数据源，只能靠每日 PE 快照长期累积（第 5 节）；一次性脚本没有历史可算，S3 永远 n/a。
2. **中断后恢复：** 追加式日志与状态文件使失败运行不破坏已有产物，下次运行从上次成功状态继续，重跑幂等。
3. **信号历史追踪：** `qqq_valuation.csv` 逐日累积，可回看任意日期的信号、当时参数与降级状态，支持事后复盘与人工抽查。
4. **参数版本演进：** `min_signals_required`、均线窗口、`min_pe_history` 等参数未来可能调整；估值 CSV 逐行记录当时参数值，规则变更后历史信号仍可解释、可复现。

## 10. 声明

本工作流输出为**研究信号**，仅反映价格与估值指标的历史相对位置，**不构成投资建议或资金授权**。任何据此进行的交易决策及其后果由使用者自行承担。
